## Version LinkedIn (portfolio / réseau professionnel)

> 🦇 **J'ai développé ChiroTool, un outil libre pour les chiroptérologues.**
>
> Dans les bureaux d'études naturalistes, le traitement des enregistrements
> ultrason de chauves-souris (protocole Vigie-Chiro Point Fixe du MNHN) est une
> tâche **chronophage et répétitive** : renommer les fichiers, appliquer
> l'expansion temporelle, créer la participation en ligne, uploader, attendre
> l'analyse automatique, nettoyer les résultats dans Excel… Multiplié par des
> dizaines de nuits par campagne.
>
> **ChiroTool automatise toute cette chaîne** depuis une interface unique, en
> local. Quelques chiffres sur le projet :
>
> 🔧 Python · CustomTkinter · SQLite · extension Rust · API REST Vigie-Chiro
> 📦 Application portable Windows (un seul exécutable)
> ⚡ Upload parallèle (3-5× plus rapide), expansion temporelle accélérée
> 📊 Graphes d'activité, suivi de campagne multi-utilisateurs, export de données
> 🆓 Libre et open-source (licence MIT)
>
> Un projet né d'un besoin de terrain, développé en grande partie sur mon temps
> personnel, avec le soutien d'Acer Campestre. Il est aujourd'hui testé par
> plusieurs chargés d'études avant une diffusion plus large.
>
> Tutoriel et démonstration disponibles. Curieux d'échanger avec d'autres
> naturalistes ou développeurs intéressés par l'écologie computationnelle !
>
> #Chiroptères #Biodiversité #OpenSource #Python #Naturalisme #VigieChiro

## Conseils de diffusion

- **Accompagne d'une courte vidéo** (60-90 s) montrant le workflow : déposer un
  dossier → 3 clics → graphe final. Le concret convainc plus que le texte.
- **Tague** Acer Campestre, et éventuellement Vigie-Chiro / MNHN (en restant
  factuel : c'est un outil tiers qui utilise leur API publique, pas un outil
  officiel MNHN).
- **Réponds aux commentaires** : les premiers retours utilisateurs sont une mine
  d'or pour la suite et créent de l'engagement.
- Sur LinkedIn, **poste en milieu de semaine, le matin** pour la visibilité.
